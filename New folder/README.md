# The Fein Heit Boutique — Luxury Beauty Parlour & E-Commerce Web Platform

A luxury, responsive multi-page web application designed for **The Fein Heit Boutique**, showcasing beauty parlour treatments, artisanal cosmetics, client engagement, and seamless online shopping with real-time order tracking.

---

## 🌟 Key Features & Pages

1. **Home Page (`#home`)**:
   - High-impact luxury hero banner with dual CTAs ("Explore Shop" & "Book a Parlour Ritual").
   - Attractive offers & promo code banner (`FEINHEIT20` for 20% off).
   - Best-selling organic skincare showcase with instant Cart & Wishlist actions.
   - Signature parlour rituals preview (HydraFacial, Balayage, Bridal Glam, Head Spa).
   - Brand value pillars (100% Organic, Cruelty-Free, Certified Master Estheticians).
   - VIP Beauty Concierge newsletter subscription.

2. **About Us Page (`#about`)**:
   - Boutique heritage & story.
   - Formal Vision & Mission statements.
   - Master Estheticians and Stylists profiles with direct appointment booking.
   - Parlour standards & clean beauty sustainability commitment.

3. **Collections Page (`#collections`)**:
   - 6 Curated beauty categories: *Skin Radiance & Anti-Aging*, *Hair Couture & Scalp Therapy*, *Luxury Fragrances*, *Organic & Vegan Cosmetics*, *Bridal & Gala Glam*, *Nail Artistry & Hand Spa*.
   - One-click navigation that automatically filters the product catalog.

4. **Products Catalog Page (`#products`)**:
   - Multi-faceted filtering: Category chips, Live keyword search, Price range slider ($30–$200), and Star rating filter.
   - Sorting options: Popular/Featured, Price: Low to High, Price: High to Low, Highest Rated, Alphabetical.
   - Product Quick View modal with ingredients, ritual usage guide, and quantity stepper.

5. **Testimonials & Reviews Page (`#testimonials`)**:
   - Average score summary (4.9 / 5.0) and star breakdown.
   - Star rating filtering (5 Stars, 4 Stars & Up).
   - Interactive "Write a Review" form with dynamic 5-star picker and local persistence.

6. **Contact Details & Parlour Info (`#contact`)**:
   - Boutique address, phone concierge, email, and weekly opening hours table with "Open Today" status badge.
   - Secure Contact Form with field validation and simulated instant response.
   - Frequently Asked Questions (FAQ) interactive accordion.

7. **Cart & Sliding Drawer (`#cart`)**:
   - Live sliding cart drawer + dedicated full cart page.
   - Free Express Shipping dynamic progress bar ($75 threshold).
   - Coupon code system (`FEINHEIT20` = 20% discount, `WELCOME10` = 10% discount).
   - Interactive checkout modal with multi-payment choices (Credit Card, Apple Pay, Pay on Parlour Pickup).

8. **Wishlist (`#wishlist`)**:
   - Dedicated wishlist page with "Move All to Bag" and individual item controls.

9. **Order Tracking System (`#tracking`)**:
   - Real-time order lookup with demo tracking IDs (`FH-89241`, `FH-10492`) and all newly generated checkout IDs.
   - 5-step visual progress timeline (Placed → Formulated in Boutique → Dispatched → Out for Delivery → Delivered).
   - Shipping address and itemized summary breakdown.

10. **Online Parlour Appointment Booking (`#booking`)**:
    - Select Service, Master Esthetician / Stylist, Date picker, and Time Slot chips.
    - Generates a digital booking voucher with Booking Reference ID (`BK-XXXXX`).

## 🚀 How to Run

Simply open `index.html` in any modern web browser or serve via any static HTTP server:

```bash
# Optional: using Python's built-in server
python -m http.server 8080

# Or using Node
npx serve .
```
